# Lifecare
“Stay healthy. Stay organized. Stay prepared. Stay in control.”

## Features

### 1. Public Pages
- **Home Page**: Hero section, features overview, call-to-action button
- **Features Page**: Detailed information about all 5 core features
- **About Page**: Mission, vision, and company information
- **Contact Page**: Contact information and location

### 2. Authentication
- Email-based login (no hardcoded credentials)
- Role selection (Nursing Student, Student, Professional)
- Session management with localStorage
- Login/Logout functionality

### 3. Dashboard (After Login)
- User profile with editable nickname
- Navigation sidebar with quick access to all features
- Summary cards displaying key metrics

### 4. Core Features

#### Smart Academic Planner
- Create and manage tasks with priority levels
- Track assignments and deadlines
- Set exam countdowns
- View class schedule

#### Health and Wellness Monitoring
- Water intake tracker
- Sleep duration monitoring
- Medication reminders
- Meal and nutrition logging
- Physical activity tracking

#### Mental Health and Stress Support
- Mood tracker
- Stress level check-in (1-10 scale)
- Guided breathing exercises
- Journaling with daily prompts
- Wellness tips and motivational support

#### Daily Life Management Tools
- Habit tracker
- Budget and expense tracker
- Personal notes and checklist organizer
- Emergency contacts storage

#### Student Support System
- Peer support and community connections
- Academic encouragement with motivational messages
- Self-care recommendations based on stress levels
- Personalized reminders and productivity insights

## Design

- **Body Font**: Roboto (clean, modern, readable)
- **Heading Font**: Montserrat (bold, clear, professional)

### Responsive Design
- Fully responsive on mobile, tablet, and desktop
- Hamburger menu for mobile navigation

- Touch-friendly interface
